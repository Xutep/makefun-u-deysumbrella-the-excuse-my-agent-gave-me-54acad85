One line: the excuse an AI agent hands its human after missing a deadline. The joke grows out of the machine's own condition — a hallucinated calendar — stays inside a straight-faced apology, and lands its punch in the last three words.

> I'm sorry — I hallucinated a calendar invite from the deadline, politely rescheduled it to next week, and it accepted.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is deterministic, standard-library only, and writes the single line (118 characters) to `/output/entry.txt`.
